## 🔬 What I'm Building

**Continuous Intelligence Layer for Biologics Discovery** — an agentic system (LangGraph + FastAPI) that turns biomarker, literature, and experimental signals into standing hypotheses for target and candidate evaluation, rather than one-off analyses.

**Protein & Molecular Design Pipelines** — full-stack orchestration of protein foundation models (RFdiffusion3, Chai-1, Boltz-2, ProteinMPNN) for generative biologics design at scale.

**Scientific Knowledge Intelligence** — hybrid GraphRAG and causal knowledge graphs over scientific literature and experimental data, built for natural-language querying and evidence-driven decision making.

**Lab Data → Active Learning Closed Loop** — pipelines that route wet-lab experimental data into a central data layer feeding agents' active learning loop, so each new experiment updates model confidence and steers the next round of candidate selection.
